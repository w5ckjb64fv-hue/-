# 原点·共治 V8.0

**AI原生街区公共价值治理推演平台｜普通案例模式 × 自由沙盘模式 × D自由回答 × 五角色代理群聊 × 流式输出 × 关注雷达 × 主体记忆 × 因果网络**

V8.0 的核心变化是加入“双模式切换”：**普通模式**只使用15张原有案例卡，不抽取35张随机特殊事件，适合正式答辩和案例教学；**自由模式**才启用完整50张事件卡、时间随机种子与特殊情景，适合开放探索和重复实验。两种模式都保留 D自由回答、5轮×5主体群聊、主体记忆、最终雷达、因果网络、图文资料库和独立案例问答助手。

## 一、直接启动

### Windows
1. 安装 Python 3.10 或更高版本，并勾选 **Add Python to PATH**。
2. 解压整个文件夹。
3. 双击 **`启动产品.bat`**。
4. 浏览器访问 `http://127.0.0.1:7860`。

### Mac / Linux
```bash
./start.sh
```

项目仍然是**零第三方 Python 依赖**，不需要 Flask、Node.js 或 npm。

## 二、配置 AI Ping

第一次启动会自动从 `.env.example` 创建 `.env`。编辑：

```text
AIPING_API_KEY=你的Key
AIPING_MODEL=DeepSeek-V3.2
```

没有 Key 时自动运行本地保障模式；有 Key 时，事件协商使用 AI Ping `chat/completions` 的 `stream: true` 流式接口。

比赛提交前请删除包含真实 Key 的 `.env`，只保留 `.env.example`。

## 三、V8.0 核心机制

### 1. 50 张事件卡库
整个案例被拆成 10 个治理阶段，每个阶段 5 张候选卡，总计 50 张：

- 15 张来自原案例主线或从原案例矛盾直接拆出的状态分支；
- 35 张新增“情景推演卡”，如融资成本变化、关键租户阻滞、算力成本、机器人配送拥堵、夜间噪声投诉、数据共享与隐私边界、外围节点资源公平、关键负责人变动等。

**新增卡均明确标注为“情景推演”，不代表案例中真实发生。**

### 2. 时间随机种子
每次点击“开始推演”，浏览器读取当前毫秒时间并生成本局随机种子。

每个阶段使用“本局种子 + 阶段编号”产生确定性随机数，再结合：
- 当前公共价值状态；
- 当前运行条件；
- 外部情景参数；
- 事件卡随机权重；

从该阶段 5 张候选卡中抽取本轮事件。

同一个随机种子可以复现同一组随机选择。默认重新开始会按新的当前时间生成种子；若需要复现实验，可在网址后加 `?seed=123456789` 固定种子。

随机概率只是教学模拟机制，不代表现实发生概率。

### 3. 每题固定 D“自由回答”
除 A/B/C 预设选项外，每题都有：

**D. 自由回答**

点击后可以直接输入自己的治理策略。

自由回答不预先赋固定分值。流程为：

```text
输入自定义方案
→ 五角色进行完整5轮群聊
→ AI/本地保障规则解析方案的机制含义
→ 生成克制的模拟状态变化
→ 写入下一题和最终治理路径
```

自由回答生成的状态变化属于沙盘机制，不是实证政策效果。

### 4. 五角色代理拥有不同“利益函数”
五个角色不只是换名字，而是分别拥有：
- 决策规则；
- 风险偏好；
- 证据关注点；
- 红线；
- 偏好的政策工具；
- 说话和论证方式；
- 跨题记忆。

角色差异：

- **政府**：制度、城市功能、公共目标、跨部门责任；
- **集体经济组织**：现金流、机会成本、资产安全、退出条件；
- **运营方**：SOP、容量、人力、时段、维护、异常处置；
- **创业企业**：资源密度、融资、算力、人才、试错速度、合作转化；
- **居民与公众**：安全、公平、可进入性、生活干扰、反馈有效性。

提示词明确禁止五个角色使用同一种论证结构和同质化风险清单。

### 5. 每题 5 轮 × 5 主体 = 25 次发言
每题协商结构：

1. **独立立场**：120–180 字，先形成自己的判断；
2. **群聊质询 · 第一圈**：220–320 字，每人同时回应至少 2 名其他主体，反驳至少 1 点并提出至少 2 个问题；
3. **群聊交锋 · 第二圈**：220–320 字，回答群内多个问题，并说明自己的判断标准为什么与别人不同；
4. **条件交换**：160–240 字，明确“我愿意让什么 / 我要求什么”；
5. **最终表态**：180–260 字，给出最终支持理由、最重要未决风险、仍会带入下一题的底线，并生成关注雷达。

第二、三轮不是“一人只回应一个人”，而是模拟一个共享群聊场景。

### 6. 真流式输出
配置 AI Ping Key 后，事件协商使用后端标签协议解析模型流。

模型一旦进入某个角色正文，浏览器立即开始逐段显示该角色发言，不需要等待：
- 该角色全文生成完成；
- 其他四个主体生成完成；
- 整轮或五轮协商全部完成。

若 AI Ping 中断，系统会显示切换提示并自动补上本地保障内容，避免比赛现场卡死。

### 7. 第五轮五张语义雷达
五个主体最终表态旁分别展示五维雷达：
- 资产可持续
- 创新活力
- 多元协同
- 空间开放
- 公众获得感

雷达表示**最终发言的议题关注强度**，不是绩效、满意度或政策效果。

### 8. 主体跨题记忆
系统持续记录：
- 最近承诺；
- 最近支持条件；
- 上一轮支持度；
- 信任状态；
- 上一轮最终立场；
- 已参与事件数。

下一题会把这些记忆再次交给角色。角色若改变立场，需要说明原因。

### 9. 治理因果网络
最终报告把实际经历的 10 个决策节点与 11 个治理维度连接起来：
- 5 个公共价值指标；
- 6 个运行条件。

网络展示的是**沙盘预设机制上的路径影响**，不等同于实证因果识别。

## 四、AI 市长挑战
AI 市长挑战也升级为 5 轮群聊：
1. 独立立场
2. 群聊质询
3. 群聊交锋
4. 条件交换
5. 最终协议 + 五主体雷达

用户可以完全自由输入新的街区治理方案。

## 七、比赛时可以这样解释

> “我们没有让大模型替治理者直接给答案，而是把一个案例做成可重复的治理实验。每次进入都有不同的随机事件组合；用户既可以选择预设策略，也可以自由提出方案。五个角色代理带着各自的利益函数和历史承诺进入共享群聊，公开展示质询、反驳、让步和最终条件。最后再用关注雷达与治理因果网络复盘：为什么同一个决策在不同主体眼里意味着不同的价值。”

## 八、学术边界

产品始终区分四层：
1. **案例事实**：来自团队案例材料；
2. **随机情景卡**：基于案例矛盾设计的教学模拟，不代表真实发生；
3. **AI协商、自由回答语义影响与雷达**：模型/规则推演，不是实证测量；
4. **因果网络**：展示沙盘机制与路径依赖，不宣称现实因果关系。


## V8.0 新增
- 新增 **案例图文资料库**：内置5张公开来源图片、案例脉络卡片、政策/资料依据卡片，便于评审先理解案例再进入沙盘。
- 新增 **独立案例问答助手**：独立于模拟沙盘，可直接就案例事实、政策依据、公共价值、多主体共治、作品创新点等进行问答。优先调用团队案例摘要与公开资料；有 AI Ping Key 时可得到更自然的回答，无 Key 时仍有本地知识库回退。


## V8.0 新增：普通 / 自由双模式

- **普通模式（默认、推荐答辩）**：只使用15张原有案例卡，严格排除35张随机特殊事件。前四阶段和最终阶段走真实主线，中间阶段根据前序状态进入对应的真实案例分支，因此有路径差异但没有虚构随机事件。
- **自由模式**：启用完整50张事件卡、时间随机种子、状态触发和35张随机特殊事件，保留可复现实验种子。
- 两种模式都保留 A/B/C + D自由回答、5轮×5主体群聊、流式输出、主体记忆、雷达图、因果网络、案例图文和案例问答助手。
- 修复 D自由回答后的UI拉伸：自定义原文改为折叠查看，状态变化卡固定双栏比例，语义影响说明单独占整行；长文本不会再把状态卡拉变形。


## V8.0 新增：成就回忆墙
- 每次完整模拟结束后，最终报告会额外生成一条 **严格一句话的本局回忆**。
- 回忆风格在 **文艺 / 实际 / 官方** 三种表达之间变化；AI Ping 已配置时由模型根据完整模拟路线生成。
- 同时生成一个 **4—8字成就称号**，与治理类型、模式、综合分、最强指标一起写入便利贴。
- 便利贴写入项目目录 `data/memory_wall.json`；关闭浏览器或重启产品后仍会保留，并支持 JSON 导出、合并导入、覆盖导入。
- 回忆墙支持单张删除和一键清空。


## V8.0：本地 JSON 回忆档案

回忆墙不再依赖浏览器 `localStorage`。当前版本由本地 Python 服务直接读写：

`data/memory_wall.json`

支持：
- 每局结束自动追加一条回忆记录；
- 单张删除与整墙清空；
- “导出 JSON”备份；
- “导入 JSON”合并已有回忆；
- “导入 JSON”覆盖当前回忆；
- JSON 使用固定 schema，可在其他电脑或另一份产品目录中恢复。

项目默认最多保留 200 条记录。整个产品文件夹移动时，`data/memory_wall.json` 会随项目一起移动。

## V8.0：图文与文献资料库扩容

- 案例图从 5 张扩展到 **14 张**。原有 5 张为本地图片；新增图片来自北京海淀/北京日报等公开页面，采用联网加载并保留来源链接。网络不可用时会显示“图片需联网加载”的占位卡，不影响文字内容和沙盘运行。
- 政策、案例报道与学术参考资料扩展到 **17 条**。
- 新增理论支撑包括创新街区（innovation districts）、协同治理（collaborative governance）、公共价值治理（public value governance）、中国参与式城市更新与北京微更新案例等。
- 案例问答助手会把这些新增材料一起纳入本地检索范围。

> 图片用于赛事案例教学与演示。若后续将产品公开发布或商业传播，建议再次核验图片授权与转载要求。
